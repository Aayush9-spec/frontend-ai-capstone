## 3. Production Documentation Package

### Quick Start Guide
```bash
# Clone the repository
git clone https://github.com/Aayush9-spec/frontend-ai-capstone.git

# Navigate to project root
cd frontend-ai-capstone

# Install dependencies
npm install

# Set up environment variables (.env.local)
GEMINI_API_KEY=your_gemini_api_key_here

# Run local development server
npm run dev
```

## 4. Architecture Overview

- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, Three.js / React Three Fiber.
- **Backend Services:** Next.js Serverless Route Handlers, Google Gemini API, Vercel Web Analytics.
- **Testing & Quality:** Vitest, React Testing Library, Playwright E2E, ESLint, GitHub Actions CI.
